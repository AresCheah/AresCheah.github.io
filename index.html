USS: Unifying Spatial-Semantic Prompting for End to End Embodied Visual Tracking
Yuchen Xie*, Xinyu Zhou*, Kuangji Zuo, Yanshuo Lu, Fengrui Huang, Boyu Ma, Jianfei Yang†
Paper / Project

USS lets a robot follow a target specified by text, a point, a box or a mask, mapping any of these prompts to egocentric waypoints end to end. Policies trained only in simulation transfer zero-shot to a real humanoid robot across 320 real-world trials.

Beyond Teacher Assignment: Domain-Normalized Multi-Teacher On-Policy Distillation
Xin Li, Hao Jiang, Xin Gao, Annan Wang, Yuchen Xie, Jinghao Guo, Xingwei Qu, Yichi Zhang, Chau Yuen
Paper / Project / Code

DN-MOPD keeps label routing in multi-teacher on-policy distillation but rescales each domain's teacher feedback by its measured spread, so that no single domain dominates the shared student.
